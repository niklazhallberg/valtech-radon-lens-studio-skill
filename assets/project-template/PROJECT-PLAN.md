## Risk log

Standard risks for Sponsored Lens projects. Adjust likelihood per project context.

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| MCP setup eats >90 min | Medium | Medium | Timebox to 90 min; skip MCP if struggling, build manually |
| FPS drops on mid-range Android | Low–Medium | High | 2D-first design, ASTC compression, no `onUpdate` loops, profile early |
| Snap rejects copy as policy violation | Medium | High | Strict tone guidelines, internal review before submission, category-specific compliance check |
| Texture sizes blow lens budget | Low | Medium | Pre-defined max sizes (1024×1024), ASTC from start, audit before Phase 5 |
| Wrong icon spec at submission | Low | Low | 320×320 simplified graphic, verify against developers.snap.com at submission |
| Client copy/asset delivery delayed | Medium | High | Lock final-copy deadline at Phase 4, build with placeholders, swap at Phase 5 |
| Scope creep from client mid-project | Medium | High | Lock scope at Phase 0, capture new ideas as v2 candidates only |
| Snap Ad Account permissions missing | Low | High | Verify access during Phase 1.5, contact media agency early if missing |
| LS 5.x API surface changes between versions | Low | Medium | Run capability validation (Phase 1.5) on current LS version, document findings |
