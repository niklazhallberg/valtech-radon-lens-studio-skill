# What is Lens Studio?

Lens Studio is Snap AR's free AR development platform. Create viral selfie Lenses and shoppable try-on experiences, or develop never-before-seen ways of connecting with the world around you. With zero setup time and seamless integration with Snapchat, [Spectacles](/spectacles/home.md), and your mobile and web applications through [Camera Kit](/camera-kit/home.md), you can build AR for anywhere.

Building Lenses for Snapchatters around the world can also be rewarding. By opting into the [Lens Creator Rewards Program](/lens-studio/monetization/lens-creator-rewards.md), you can be eligible to earn a payout for building top performing Snapchat Lenses.

Lens Studio includes a number of Sample Projects to help you get started making Snapchat Lenses. For the always popular Face Lenses you see on Snapchat, make sure to check out the wide variety of [Face Templates](/lens-studio/features/ar-tracking/face/face-effects-overview.md). If you're new here, check out the AI Assistant (Q\&A Chat) that can answer your development questions. Also in the GenAI Suite, are powerful and fun tools like Immersive Machine Learning effects or 3D Body Morph that can help you create a Lens in minutes.
