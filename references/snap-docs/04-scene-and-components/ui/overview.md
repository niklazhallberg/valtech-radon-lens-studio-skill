## UI Custom Components[​**](#ui-custom-components "Copy to clipboard")

Outline of the ui custom components we have and how to use them

[![](/img/lens-studio.svg)](/lens-studio/features/ui/ui-widgets.md)

[UI Widgets](/lens-studio/features/ui/ui-widgets.md)

[With Lens Studio’s UI Widget Custom Components you can create custom interactable interfaces to overlay on your Lenses.](/lens-studio/features/ui/ui-widgets.md)

[![](/img/lens-studio.svg)](/lens-studio/features/ui/flexbox.md)

[FlexBox Layout](/lens-studio/features/ui/flexbox.md)

[The Horizontal and Vertical Layout Components work by positioning all the Layout Elements on child Scene Objects into the space allotted to the Layout Component by driving the properties of their ScreenTransform.](/lens-studio/features/ui/flexbox.md)

[![](/img/lens-studio.svg)](/lens-studio/features/ui/ui-scroll-view.md)

[UI Scroll View](/lens-studio/features/ui/ui-scroll-view.md)

[The UI Scroll View is allows you to scroll one screen transform within the bounds of another.](/lens-studio/features/ui/ui-scroll-view.md)

[![](/img/lens-studio.svg)](/lens-studio/features/ui/ui-image-carousel.md)

[Image Carousel](/lens-studio/features/ui/ui-image-carousel.md)

[Image Carousel is a rotary UI element that enables the selection of one item between many. To select items users can swipe to rotate the carousel or tap on an icon..](/lens-studio/features/ui/ui-image-carousel.md)

[![](/img/lens-studio.svg)](/lens-studio/essential-skills/ui/camera-roll-widget)

[Camera Roll Widget](/lens-studio/essential-skills/ui/camera-roll-widget)

[The Camera Roll Widget allows users to select multiple images from their Camera Roll to use in your Lens.](/lens-studio/essential-skills/ui/camera-roll-widget)
