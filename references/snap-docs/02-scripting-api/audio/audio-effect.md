# Audio Effect

This guide walks you through how to add Audio Effects in your Lens. Audio Effects are applied to the audio that the microphone recorded. Audio Effects are only applied after the user records a Snap. You can use audio effects to, for example, pitch shift the user's voice up so that they sound like a cute animal.

## Add an Audio Effect Component[​**](#add-an-audio-effect-component "Copy to clipboard")

You can add an `Audio Effect` component on any Scene Object. After selecting the Scene Object, in the `Inspector` panel, you can select `+ Add Component -> Audio -> Audio Effect`.

![](/assets/images/audio-effect-1-36a2058ee1ed0acc02074a285af25a51.png)

## Select Audio Effects[​**](#select-audio-effects "Copy to clipboard")

Lens Studio includes a number of built-in audio effects you can apply to your Lens. With the Audio Effect object selected, the Audio Effect can be tuned in the `Inspector` panel via the `Effect Preset` dropdown.

![](/assets/images/audio-effect-2-63b1187f219c19cc66eccd73e8b63c22.png)

[](http://tinypng.com/)You can only have one audio effect in your Lens. If you add multiple audio effect components, only one will be applied.

## Preview Audio Effects[​**](#preview-audio-effects "Copy to clipboard")

In the `Inspector` panel, you can pick from the provided set of audio samples and hear how the sample recording sounds like before and after applying the audio effect.

[](/img/lens-studio/5-learning-lens-studio/audio-effect-3.webm)

Additionally, you can send the Lens to your device and record a Snap to hear the resulting audio effect on device. For more information on sending your Lens to device, follow the [Pairing to Snapchat](/lens-studio/lens-studio-workflow/pairing-to-snapchat.md) guide.
