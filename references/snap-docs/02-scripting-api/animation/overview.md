# Overview

This page provides details on all building blocks one may need to implement animations in Lens Studio.

<!-- -->

<!-- -->

## Working with Animations[​**](#working-with-animations "Copy to clipboard")

[![](/img/lens-studio/icon-animation-player.svg)](/lens-studio/features/animation/animation-player.md)

[Animation Player](/lens-studio/features/animation/animation-player.md)

[The Animation Player component handles animations on 3D objects. It deals with Animation Clips, Animation Assets, and more.](/lens-studio/features/animation/animation-player.md)

[📄️](/lens-studio/features/animation/animation-events.md)

[Animation Events](/lens-studio/features/animation/animation-events.md)

[The Animation Events system allows you to trigger other behaviors based on an animation timeline.](/lens-studio/features/animation/animation-events.md)

[📄️](/lens-studio/features/animation/playing-animations-programatically.md)

[Playing Animations Programatically](/lens-studio/features/animation/playing-animations-programatically.md)

[You can trigger animations through script, and even transition between them.](/lens-studio/features/animation/playing-animations-programatically.md)

[📄️](/lens-studio/features/animation/animating-scene-objects.md)

[Animating Scene Objects](/lens-studio/features/animation/animating-scene-objects.md)

[Create transform animations on scene objects using the Animate action, transport controls, and live keyframe recording from the viewport.](/lens-studio/features/animation/animating-scene-objects.md)

[![](/img/lens-studio/icon-curve-editor.svg)](/lens-studio/features/animation/anim-curve-editor.md)

[Curve Editor](/lens-studio/features/animation/anim-curve-editor.md)

[The Curve Editor provides an interface to author animation curves, including Bezier tangent handles, a clips bar, transport controls, and keyframe recording.](/lens-studio/features/animation/anim-curve-editor.md)

[📄️](/lens-studio/lens-studio-workflow/adding-interactivity/tween-manager.md)

[Tween Manager](/lens-studio/lens-studio-workflow/adding-interactivity/tween-manager.md)

[The Tween Manager is a helper script that allows you to create simple programmatic animations like moving, rotating, changing the color of an object, and more.](/lens-studio/lens-studio-workflow/adding-interactivity/tween-manager.md)
