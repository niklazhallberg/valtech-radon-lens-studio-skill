# Package Manager

You can access your `Package Manager`, by selecting `Lens Studio > Preferences` or via the toolbar option `Package Manager`.

Here you will see a list of all items in your `Installed Library` under `Lens Studio Installed Content`. A list of all items in your `Packages Folder` or project under `Project Installed Content`. Each item will have their icon, name and version displayed.

![](/assets/images/package-management_6-c059e43bb452827f243aadbcb783e8f4.png)

## Installed Library[​**](#installed-library "Copy to clipboard")

All installed Custom Components and Packages are saved in the following locations by default:

You may add your own folders to the `Installed Library Locations` by selecting Lens Studio in the menu bar, located at the top, and selecting `Preferences`

![](/assets/images/script-management-2-f21455f1cc4c15d52dea2b9e0d01a198.png)

You may add a shared or version controlled folder to manage and share assets with other Lens Developers.

## Packages Folder[​**](#packages-folder "Copy to clipboard")

When scripts use external dependencies, we copy over the dependencies into the `Packages` folder. This folder can be found in your project directory and in the asset browser. To add items from your `Installed Library` to your `Packages` folder, you can select the `Install to Project` button beside the asset you'd like to move.

![](/assets/images/package-management_7-c13282bdae74d76c819eece7a0b26af0.png)

## Installed Content Settings[​**](#installed-content-settings "Copy to clipboard")

For each installed content, you will be able to uninstall, share or select a different version.

![](/assets/images/package-management_8-b251c70c0a64b8c48422ea177d0d0047.png)
