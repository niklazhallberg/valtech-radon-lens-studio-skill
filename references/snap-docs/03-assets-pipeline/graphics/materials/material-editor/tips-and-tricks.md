# Material Editor Tips and Tricks

This page contains some common tips and tricks that will help you use the Material Editor more efficiently.

## Commonly Used Shortcuts[​**](#commonly-used-shortcuts "Copy to clipboard")

### Node Preview[​**](#node-preview "Copy to clipboard")

Press `P` on the keyboard to open the Node preview

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_node_preview.webm)

### Change View Modes[​**](#change-view-modes "Copy to clipboard")

Press the up and down arrow keys to change the view mode of the node

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_view_modes.webm)

### Select Connected Nodes[​**](#select-connected-nodes "Copy to clipboard")

Press the `left arrow key` on the keyboard to select nodes connected to the left of the current node.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_left_arrow.webm)

Press the `right arrow key` on the keyboard to select nodes connected to the right of the current node.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_right_arrow.webm)

### Duplicate Selected Nodes[​**](#duplicate-selected-nodes "Copy to clipboard")

Press `Cmd + D` on the Mac or `Ctrl + D` on Windows to duplicate the selected nodes.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_duplication.webm)

You can also do this by holding `Space` on the keyboard and dragging nodes.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_space_duplication.webm)

### Delete Selected Nodes[​**](#delete-selected-nodes "Copy to clipboard")

Press the `Delete` key on Mac or `Backspace` key on Windows to delete the selected node.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_delete.webm)

### Delete Selected Nodes with Auto-Reconnect[​**](#delete-selected-nodes-with-auto-reconnect "Copy to clipboard")

Press `Shift + Delete/backspace` to delete the selected node while connecting the previous and following node.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_shift_delete.webm)

### Show Graph in Full Window[​**](#show-graph-in-full-window "Copy to clipboard")

Press `F` on the keyboard to fullscreen the entire graph.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_f_key.webm)

### Create Sub-graph[​**](#create-sub-graph "Copy to clipboard")

Select nodes and press `Cmd + G` on Mac or `Ctrl + G` on Windows to create a sub-graph.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_create_subgraph.webm)

### Using Shift[​**](#using-shift "Copy to clipboard")

In many cases, you can use Shift on the keyboard to perform additional functions.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_shift_cut.webm) [](/img/lens-studio/tips-and-tricks_tips_and_tricks_shift_remove.webm) [](/img/lens-studio/tips-and-tricks_tips_and_tricks_shift_insert.webm) [](/img/lens-studio/tips-and-tricks_tips_and_tricks_shift_add.webm)

### Create Nodes from Input/Output Ports[​**](#create-nodes-from-inputoutput-ports "Copy to clipboard")

Dragging a connection from a port and ending it in empty space will bring up the Add Node menu automatically.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_create_from_input.webm)

### Using Comments[​**](#using-comments "Copy to clipboard")

Select a group of nodes, then use the right click menu to create helpful comment groups. You can also use `Cmd + B` on Mac or `Ctrl + B` on Windows.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_comment_group.webm)

### Using Passthrough[​**](#using-passthrough "Copy to clipboard")

Click on a connection line to create a passthrough node.

[](/img/lens-studio/tips-and-tricks_tips_and_tricks_passthrough.webm)
