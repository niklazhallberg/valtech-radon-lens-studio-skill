# Compatibility

[SnapML](/lens-studio/features/snap-ml/ml-overview.md) optimizes the execution of your model by leveraging device-specific hardware acceleration when available. This page provides information on which ML layers are available for acceleration.

✔️ indicates availability. ❌ indicates unavailability.
