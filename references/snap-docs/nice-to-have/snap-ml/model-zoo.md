# Model Zoo

This page contains additional example models that you can bring into Lens Studio to unlock new capabilities through [SnapML](/lens-studio/features/snap-ml/ml-overview.md). To import a model into Lens Studio, drag and drop the .ONNX file into the `Asset Browser` panel. Refer to the [ML Component](/lens-studio/features/snap-ml/ml-component/ml-component-overview.md) guide and the relevant [templates](/lens-studio/features/snap-ml/snap-ml-templates/classification.md) to learn more about using these models.

You can download additional models from the [Asset Library](/lens-studio/assets-pipeline/asset-library/asset-library-overview.md) within Lens Studio.

These models detect a single composite class that consists of related objects. You can use these models to detect object locations on the screen in combination with classification models.
