# Lens Cloud

Power a new generation of AR experiences that are more dynamic and interactive than ever before.

Lens Cloud is a collection of backend services, built on the same infrastructure that powers Snapchat. Lens Cloud vastly expands what developers can build in augmented reality; from creating unique Multi-User content that can be experienced together among friends and family, to bringing the world around you to life using Location Services, by building persistent experiences users can come back to with Storage Services and discovering more about the world around you with Scanning Services. Lens Cloud powers a new generation of AR experiences that are more dynamic, useful, and interactive than ever before.

<br />

Currently, Lens Cloud Features cannot be used in Sponsored Lenses

## Lens Cloud Features

## Multi-User Services

Multi-User Services provides developers the ability to build and create multi-user AR content to create unique shared experiences. With updates to the Connected Lenses and introduction of new high level Multi-User APIs, Lens Cloud makes it easier than ever to build collaborative experiences.

* [Connected Lenses Overview](/lens-studio/features/connected-lenses/connected-lenses-overview.md)
* [Connected Lenses Template](/lens-studio/features/connected-lenses/connected-lenses-templates/connected.md)
* [Sharing Data Between Participants](/lens-studio/features/connected-lenses/sharing-data.md)

## Location-Based Services

Location-based AR builds upon Snap’s work with Landmarkers to create location based content around the world. Lens Cloud offers developers to expand their experiences by creating their own location-based content via Custom Location AR and with City-Scale Templates you can create AR experiences for anywhere in a city we have mapped.

* [Landmarker Guide](/lens-studio/features/location-ar/guide.md)
* [City-Scale AR Template](/lens-studio/features/location-ar/city-landmarker.md)
* [Custom Location Creator Lens](/lens-studio/features/location-ar/custom-landmarker-scan.md)
* [Custom Location Template](/lens-studio/features/location-ar/custom-landmarker.md)

## Storage Services

Storage Services allows developers to expand how much content is available to their users. With Persistent Cloud Storage, developers can now create experiences that save a user’s preferences, progress and more across multiple sessions.
