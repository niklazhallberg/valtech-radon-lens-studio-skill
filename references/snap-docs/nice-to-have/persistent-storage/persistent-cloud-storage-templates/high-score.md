# High Score

## Guide[​**](#guide "Copy to clipboard")

This sample project is available on Lens Studio [Home Page](/lens-studio/lens-studio-workflow/lens-studio-interface/home.md)

The High Score sample project is a demonstration of the persistent storage system usage. Please refer to the [Simple High Score](/lens-studio/features/persistent-cloud-storage/persistent-cloud-storage-templates/simple-high-score.md) example which walks through the persistent storage functionality that drives this sample project.

[](/img/lens-studio/high-score_high_score_example.webm)

This example contains several elements that you can dissect or re-use in your experience.

* A script based collision system
* Character controller
* Game level generator
* Game state manager

To learn more about making games, checkout the [Bitmoji Runner Game](/lens-studio/tutorials/tutorials/bitmoji-runner-game/runner-game-1.md) tutorial!
