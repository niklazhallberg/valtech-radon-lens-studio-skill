# Hosted WebAR Lenses

With Hosted WebAR Lenses, any Lens developer can publish an approved custom Lens to the web via a unique URL hosted by Snap — no web development skills or background needed! This feature allows creators to publish their Lenses faster than ever before.

 Hosted WebAR Lenses uses the Camera Kit Web SDK under the hood. This means that any limitations that exist with the Camera Kit Web SDK will exist with this feature. To view the current existing limitations check out [Unsupported Lens Features](/camera-kit/ar-content/lens-studio-compatibility.md#unsupported-lens-features). To view Lens Studio compatibility check out [Lens Studio Compatibility](/camera-kit/ar-content/lens-studio-compatibility.md#camera-kit-version-parity). Additionally, this feature is limited to Lenses that are made for Web.

## Getting Started[​**](#getting-started "Copy to clipboard")

### From Lens Details Page[​**](#from-lens-details-page "Copy to clipboard")

Your Lens must be Approved by Snapchat to use this feature.

1. Navigate to [My Lenses](https://my-lenses.snapchat.com/lens-folders) and select the Lens you want to use as your Hosted WebAR Lens.

2. Scroll down to the Hosted WebAR Lens Details section. Click the Generate Hosted WebAR Lens URL.

![](/assets/images/hosted-lens-generate-053f1b5a1b5943b92714611cf3e7a19b.png)

3. This will generate a unique URL for your Lens. Click the generated URL to view your Lens in action.

![](/assets/images/hosted-lens-published-10357dbe69e3a70aeaab236fcdd4f7e3.png)

Congratulations! You’ve successfully created a Hosted WebAR Lens.

Once you’ve generated a Hosted WebAR Lens URL, you can share it with anyone. This URL will always point to the latest version of your Lens. If you need to temporarily disable the URL, you can do so by toggling the Enable WebAR Lens URL, this only temporarily disables the URL.

If you need to permanently delete the Hosted WebAR Lens URL, you can do so by clicking the Delete WebAR Lens URL button.

### From Hosted WebAR Lens Page[​**](#from-hosted-webar-lens-page "Copy to clipboard")

You must have a Lens Folder with an approved Lens to use this feature.

1. Navigate to the [Hosted WebAR Lenses](https://my-lenses.snapchat.com/hosted-lenses) page from the side navigation.

![](/assets/images/hosted-lens-page-empty-3f09cd5f024c3c3e7f5d3dda5d4676b6.png)

2. Click the Generate Hosted WebAR Lens URL button.

3. Select the Lens Folder that contains the Lens you want to use as your Hosted WebAR Lens.

![](/assets/images/hosted-lens-page-lens-folder-81547898989e9dfdbd39a56b4db607a6.png)

4. Select the Lens you want to use as your Hosted WebAR Lens.

![](/assets/images/hosted-lens-page-lens-selection-f7f6d64bf814c52ec25a4d230b177211.png)

5. Click the Generate Hosted WebAR Lens URL button.

Congratulations! You’ve successfully created a Hosted WebAR Lens.

You will now be able to view all of your Hosted WebAR Lenses on the Hosted WebAR Lenses page. From here you can view the Lens, share the Lens, update the Lens, or delete the Lens.

![](/assets/images/hosted-lens-page-list-2c9ad6adfac4d5119a3bd47609a60407.png)

#### Statuses[​**](#statuses "Copy to clipboard")

Hosted WebAR Lens URLs can have the following statuses:

* **Published**: The Hosted WebAR Lens is live and can be accessed by anyone with the URL.
* **Draft**: The Hosted WebAR Lens is not live and cannot be accessed by anyone with the URL.

If you chose to Delete a Hosted WebAR Lens URL, it will be permanently deleted and that URL cannot be recovered.
