# Cricket Helmet

The Cricket Helmet Template lets users create a customizable cricket helmet. This template is a great starting point to easily feature your own 2D artwork in a Face Lens. It comes with a configurable 3D cricket helmet which you can recolor and decorate with any image you like.

The template also features Face Mask Effects you can recolor and replace. This guide covers how to customize the cricket helmet and face mask effects, as well as how to import your own custom logo and face mask patterns.

## Guide[​**](#guide "Copy to clipboard")

To customize the cricket helmet, select the `Cricket Helmet Controller [EDIT_ME]` object in the `Scene Hierarchy` panel and adjust its settings in the `Inspector` panel. The sections below walk through each of the customizable settings.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_SelectObject.webm)

### Changing the Logo[​**](#changing-the-logo "Copy to clipboard")

You can replace the logo on the cricket helmet by changing the `Logo Texture` property to the texture of your choosing.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ChangeLogo.webm)

The template includes a few example logos you can try out. You can find them in the `Asset Browser` panel under the "Logos" folder.

![](/assets/images/cricket-helmet_Cricket_Helmet_Presets-dca76cf355b361ee826e5539825a13d0.png)

To bring in your own image as a logo, select `+ -> Import Files` in the `Asset Browser` panel. Alternatively, you can drag and drop any image from your computer to the `Asset Browser` panel.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ImportFiles.webm)

### Adjusting the Logo[​**](#adjusting-the-logo "Copy to clipboard")

You can adjust the logo size using the `Logo Size` slider.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ChangeSize.webm)

You can adjust the logo position using the `Logo Offset X` and `Logo Offset Y` sliders.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ChangeOffset.webm)

You can also adjust the logo's appearance by changing the `Logo Blend Mode` dropdown. Available blend modes are Normal, Screen, and Multiply.

### Coloring the Cricket Helmet[​**](#coloring-the-cricket-helmet "Copy to clipboard")

You can edit the cricket helmet 's color in the `Inspector` panel by changing the `Helmet Cap Color` and `Helmet Cushions Color` properties.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ChangeColor.webm)

### Toggling the Face Paint[​**](#toggling-the-face-paint "Copy to clipboard")

You can turn the face paint effect on or off by checking the `Show Face Paint` checkbox.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ToggleFacePaint.webm)

### Recoloring the Face Paint[​**](#recoloring-the-face-paint "Copy to clipboard")

You can change the colors used in the face paint by adjusting the `Primary Face Paint Color` and `Secondary Face Paint Color` properties in the `Inspector` panel.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_RecolorFacePaint.webm)

### Changing the Face Paint Patterns[​**](#changing-the-face-paint-patterns "Copy to clipboard")

You can change the Face Paint pattern by selecting a default pattern from the dropdown labeled `Face Paint Pattern`.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ChangingFacePaintPattern.webm)

### Creating Custom Face Paint Patterns[​**](#creating-custom-face-paint-patterns "Copy to clipboard")

You can use your own textures to create a Face Paint pattern by unchecking the box labeled `Use Default Pattern`.

To bring in your own image as a face paint pattern texture, select `+ -> Import Files` in the `Asset Browser` panel, or drag and drop any image from your computer to the `Asset Browser` panel.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ImportFiles.webm)

You can replace the face paint pattern textures by changing the `Primary Face Paint Texture` and `Secondary Face Paint Texture` properties.

### Toggling the Cricket Bat Animation[​**](#toggling-the-cricket-bat-animation "Copy to clipboard")

The template include a 2D Animation which can be trigger to play when you open your mouth by default.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_AnimatedSprites.webm)

You can also change the animation trigger by changing the `Animation Trigger` dropdown.

You can choose time in seconds before the event can be triggered again by changing the `Trigger Disable Time`.

[](/img/lens-studio/cricket-helmet_Cricket_Helmet_ChangeAnimationTrigger.webm)
