  Steg 01 av 04
  
Installera Claude Code

  
Claude Code är hjärnan som bygger ditt filter. Den körs lokalt på din egen dator — inget moln, inget eget extra konto utöver Anthropic-inloggningen.


  

    

      
Vad du gör

      
1. Gå till nedladdningssidan i din webbläsare:

      

        
https://claude.ai/code

        
      

      
2. Klicka på "Download" — sidan känner igen din dator (Mac, Windows eller Linux).

      
3. Öppna den nedladdade filen och följ stegen i installern. Som vilken app som helst.

      
4. När installern säger "klart" — öppna Terminal-appen (Mac: ⌘+Space, skriv "Terminal", tryck Enter), klistra in detta och tryck Enter:

      

        
claude --version

        
      

    


    

      
Vad du ser när det funkat

      
I terminalen, efter claude --version, borde du se ett versionsnummer:

      
claude code 1.x.x

      
Exakt nummer spelar ingen roll — det viktiga är att du får ett svar (inte "command not found").


      

        Funkar inte?
        
    
          
  • "command not found: claude" — installer:n körde, men terminalen vet inte var claude ligger. Stäng terminalen, öppna en ny. Funkar oftast då.
    • 
          
  • Installern öppnar inte — Mac: högerklicka på filen → Öppna → "Öppna ändå". Windows: högerklicka → Egenskaper → "Avblockera".
    • 
          
  • Vet inte vad Terminal är — det är en svart eller mörkgrön ruta där du skriver kommandon istället för att klicka. Öppna Spotlight (⌘+Space) och skriv "Terminal".
    • 
        

      

    

  









  Steg 02 av 04
  
Starta Claude Code

  
Nu öppnar du själva Claude-sessionen — det är där ni två (du och Claude) snackar.


  

    

      
Vad du gör

      
I samma terminal som nyss, skriv:

      

        
claude

        
      

      
Tryck Enter.

      
Första gången du startar Claude Code kommer den be dig logga in via webbläsaren — den öppnar automatiskt en sida hos Anthropic. Logga in där, kom tillbaka till terminalen.


      

        Behöver du konto? Claude Code kräver ett Anthropic-konto. Om du inte har ett — be din närmaste chef eller IT om access via Valtechs konto. Annars kan du fastna på login utan att förstå varför.
      

    


    

      
Vad du ser när det funkat

      
I terminalen visas en prompt — en cursor som väntar på att du ska skriva. Något i stil med:

      
Welcome to Claude Code.

Type your message to begin:
> _

      
Det streckade understrecket (cursor) blinkar. Du är inne. Allt du skriver härifrån går direkt till Claude.


      

        Funkar inte?
        
    
          
  • "You need to log in" men ingen webbläsare öppnas — kopiera URL:en som visas i terminalen och klistra in i webbläsaren manuellt.
    • 
          
  • "Account not found / unauthorized" — ditt Anthropic-konto har inte access till Claude Code-API:n. Be Valtech-IT lägga till dig.
    • 
        

      

    

  













  Steg 03 av 04 · det här är magin
  
Klistra in setup-prompten

  
Detta är det enda du egentligen behöver minnas. Kopiera texten nedan, klistra in i Claude Code, tryck Enter. Claude tar över därifrån — hen diagnostiserar vad du har, vad som saknas, och guidar dig genom det.


  

    

      SETUP-PROMPT — kopiera hela
    

    
Jag är ny användare som vill bygga ett Snapchat-filter via dig och Lens Studio. Jag har just installerat dig (Claude Code) och inget annat är på plats än. Hjälp mig komma igång.

Kör först en diagnostik på vad som finns / saknas på min maskin:

1. Lens Studio installerat? Kolla om mappen `/Applications/Lens Studio.app` finns på Mac, eller om `lens-studio` finns i PATH på Windows/Linux.

2. Skillen installerad? Kolla om `~/.claude/skills/lens-studio-snapchat-filter/SKILL.md` existerar.

3. MCP-server registrerad mellan dig och Lens Studio? Kör `claude mcp list` och leta efter en rad med `lens-studio`.

Rapportera vad du hittade — vad finns, vad saknas. Sen guida mig genom det som saknas, ett steg i taget. Vänta på mitt 'klar' efter varje steg innan du går vidare.

Förklara varje steg i klarspråk. Jag är digital designer, inte tekniker. Använd mentor-tone — du är en kollega som hjälper mig, inte ett system som kör en setup-wizard. Berätta vad jag ser i Lens Studio och i terminalen när varje steg lyckas.

När allt är på plats: fråga vad mitt lens-projekt ska handla om (klient + grov idé) och kör dina vanliga onboarding-frågor. Du är expert på filter-bygge nu — guida mig hela vägen från idé till submission.

    
  


  

    

      
Vad du gör

      
1. Klicka "Kopiera hela" på block:et ovan.

      
2. Gå tillbaka till Claude Code-terminalen (där cursor:n blinkade).

      
3. Klistra in: ⌘+V på Mac, Ctrl+V på Windows.

      
4. Tryck Enter.


      

        Det är OK att klistra in en lång text i terminalen. Claude Code kan ta emot flera rader samtidigt. Du behöver inte trycka Enter mellan raderna.
      

    


    

      
Vad du ser när det funkat

      
Claude börjar svara — först med "Jag kör en diagnostik..." eller liknande. Sen listar hen vad som finns och vad som saknas på din maskin. Något i stil med:

      
Kollar din maskin nu...

✓ Claude Code: igång (det är du som pratar med mig)
✗ Lens Studio: hittade inte appen
✗ Filter-skill: ej installerad
✗ MCP-server: ej registrerad

Vi behöver fixa tre saker. Vi tar dem en i taget...

      
Sen pratar Claude dig genom första steget — installera Lens Studio. Du följer hens guidning. Det här är HEN nu, inte manualen.

    

  











  Steg 04 av 04
  
Följ Claudes guidning

  
Härifrån är det inte längre du som följer en manual. Du följer Claude. Hen är en kollega som vet vad hen gör.


  

    

      
Vad du gör

      
Claude kommer säga vad nästa steg är. Det kan vara att:

      
    
        
  • Ladda ner Lens Studio från ar.snap.com
    • 
        
  • Klicka på en specifik knapp i Lens Studio
    • 
        
  • Klistra in en konfiguration i terminalen
    • 
        
  • Spara en fil
    • 
      

      
När du gjort steget — skriv "klar" i terminalen, tryck Enter. Claude verifierar och går vidare.


      

        Är du osäker på något steg? Säg det till Claude i klartext: "Jag förstår inte vad du menar med [X]". Hen omformulerar och förklarar enklare.
      

    


    

      
Vad du ser när allt är klart

      
När alla tre saknade delar (Lens Studio, skill, MCP) är på plats, säger Claude:

      
Allt på plats — nu kan vi börja bygga.

Berätta lite om filtret du vill göra:
- Vilken klient/projekt?
- Grov idé — vad ska användaren uppleva?
- Tidsplan om du har en

Jag drar onboarding-frågorna när du svarat på det.

      
Det är start-skottet. Härifrån är det filter-bygge — Claude vet hela vägen från idé till färdig lens.

    

  









  Allt går inte enligt plan
  
Fastnar du?

  
Det här är nytt och ovanligt. Du kommer fastna på något. Det är okej, och det finns flera vägar framåt.


  

    

      
1. Fråga Claude Code direkt

      
Har du fått Claude Code att starta? Skriv bara "Jag fastnar på <steg>: <vad du ser>". Claude växlar till felsökning automatiskt — hen frågar tillbaka tills hen förstår, och föreslår en fix.

    


    

      
2. Fråga en annan AI

      
Ingen Claude Code att fråga än? Kopiera kommandot eller felmeddelandet, klistra in i claude.ai, ChatGPT eller Gemini. Lägg till "jag försöker installera Claude Code för att bygga Snapchat-filter" så de förstår kontexten.

    


    

      
3. Be en kollega

      
På Valtech finns andra som kört detta. Skriv i er Slack-kanal (#snapchat-filter eller motsvarande) och peka på det steg som krånglar. Någon har troligen sett samma sak.

    


    

      
4. Visa mig din skärm

      
Använd din dators skärmdump-funktion (Mac: ⌘+⇧+4, Windows: Win+⇧+S). Ta bild på vad du ser i terminalen. Klistra in bilden direkt i Claude.ai eller ChatGPT — de kan SE vad som gått fel.

      
Många nybörjare vet inte hur man beskriver ett fel i text. En screenshot är enklare.

    

  









  När setup är klart
  
Vad du kan bygga

  
Lens Studio + Claude Code låter dig bygga ungefär vad som helst. Här är några vanliga första-projekt för att få en känsla för vad som är möjligt.


  

    

      
Logo som följer ansiktet

      
Brand-logo eller text som flyger in när användaren öppnar filtret, fäster vid pannan eller över axeln. Enkelt face tracking + 2D-bild.

    

    

      
Hatt, glasögon eller smycken

      
3D-modell som "bärs" av användaren. Funkar för cap, snapback, ringar, halsband, örhängen. Snap har färdiga Try-On Packs att börja från.

    

    

      
Sneakers på fötterna

      
Klassiskt try-on-filter: skor som följer användarens fötter. Vi har empirisk erfarenhet av detta i skill:en — Claude vet vägen.

    

    

      
Tap-to-reveal-effekt

      
Användaren tappar på skärmen, något fades in eller animeras — bra för kampanj-reveal eller "scratch the surface"-mekaniker.

    

  


  
När du har en idé — säg den till Claude och hen drar onboarding-frågorna. ~8 frågor i 3 block (vision, ramar, assets), ~10 min totalt. Sen börjar bygget.
