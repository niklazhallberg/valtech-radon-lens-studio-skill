Lens Studio Skill

Skapa Snapchat-filter i Lens Studio — direkt från terminalen, via Claude Code. Ett skill-paket som blir smartare ju mer vi använder det.

Förkunskaper · inga Tid · 10–15 min 

    

  









  Innan du börjar
  
Skaffa ett Claude-konto

  
Claude Code kräver inloggning med ett betalt konto eller egna API-credits — ett gratis claude.ai-konto räcker inte. Tre vägar finns; öppna den som passar dig.


  

    A. Enterprise subscription (rekommenderad — på väg)
    
På väg, mer information kommer senare.

    
Tills dess — välj väg B eller C nedan.

  


  

    B. Egen Claude Pro-prenumeration ($17–20/mån)
    
Bra om du vill ha förutsägbar månadskostnad eller redan har en Pro-prenumeration.

    
1. Gå till claude.com/pricing i webbläsaren.

    
2. Välj Claude Pro och teckna abonnemanget.

    
3. Registrera med din @valtech.com-adress (eller Google/Microsoft SSO).

    
4. Klart. Senare i Steg 07 när du kör claude i terminalen — välj "Claude account with subscription" vid login-prompten.

  


  

    C. Egen API-credit ($5–20, pay-as-you-go)
    
Bäst om du bara vill prova "lite grann". Ingen månadskostnad — du laddar på krediter och förbrukar dem per användning.

    
1. Gå till platform.claude.com/login.

    
2. Registrera med din @valtech.com-adress (eller "Continue with Google/Microsoft").

    
3. Välj "Individual" i onboarding-flödet.

    
4. Gå till API Keys → Create Key. Spara nyckeln (sk-ant-...) säkert — den visas bara en gång.

    
5. Gå till Billing → ladda på minst $10 med kort.

    
6. Senare i Steg 07 när du kör claude i terminalen — välj "Anthropic Console (API key)" och paste:a in nyckeln.

  









  Steg 01 av 08
  
Installera Claude Code

  
Claude Code är hjärnan som bygger ditt filter — byggd av Anthropic, företaget bakom AI-modellen Claude. Den körs lokalt på din egen dator, och det enda kontot du behöver är din Anthropic-inloggning.


  

    

      
Vad du gör

      
1. Öppna Terminal-appen (Mac: ⌘+Space, skriv "Terminal", tryck Enter).

      
2. Klistra in detta och tryck Enter — installationen tar någon minut:

      

        
curl -fsSL https://claude.ai/install.sh | bash

        
      

    


    

      
Vad du ser när det funkat

      
Terminalen visar nedladdning + install-steg, något i stil med:

      
Downloading Claude Code...
Installing to /usr/local/bin/claude
Installation complete.

      
När prompten är tillbaka och du kan skriva igen — installen är klar.


      

        Funkar inte?
        
    
          
  • Curl-kommandot kraschar — vanligast att internet bröts mitt i. Kör samma kommando igen.
    • 
          
  • Vet inte vad Terminal är — det är en svart eller mörkgrön ruta där du skriver kommandon istället för att klicka. Öppna Spotlight (⌘+Space) och skriv "Terminal".
    • 
        

      

    

  









  Steg 02 av 08
  
Verifiera installationen

  
Innan vi går vidare — bekräfta att claude-kommandot faktiskt nås från din terminal.


  

    

      
Vad du gör

      
I samma terminal, kör:

      

        
claude --version

        
      

    


    

      
Vad du ser när det funkat

      
Ett versionsnummer:

      
claude code 1.x.x

      
Exakt nummer spelar ingen roll — det viktiga är att du får ett svar (inte "command not found").


      

        Funkar inte?
        
    
          
  • "command not found: claude" — installationen körde, men terminalen hittar inte claude än. Stäng terminalen, öppna en ny. Funkar oftast då.
    • 
        

      

    

  









  Steg 03 av 08
  
Acceptera inbjudan

  
Skill:en bor på GitHub som ett privat repo. Niklaz har skickat dig en invitation — du behöver acceptera den för att få access.

  
GitHub är ett delat arkiv för kod och filer — tänk Google Drive fast för utvecklingsprojekt. Skill:en ligger lagrad där, så att alla på teamet kan hämta hem den, använda den och förbättra den över tid.


  

    

      
Vad du gör

      
1. Öppna mejlet från Niklaz Hallberg.

      
2. Klicka på den blå knappen View invitation.

      
3. Om GitHub ber dig logga in — logga in. Saknar du konto, klicka Create an account, fyll i uppgifter och verifiera din mejl.

      
4. När du är inloggad ser du en GitHub-sida med invitation. Klicka Accept invitation.


      

        Använd helst samma mejladress som invitationen skickades till. Annars kan GitHub säga 404 (Repository not found).
      

    


    

      
Vad du ser när det funkat

      
Efter klicket på Accept invitation visas GitHub-repots framsida med en bekräftelse:

      
You are now a collaborator on
niklazhallberg/valtech-radon-lens-studio-skill

      
Du kan nu se filerna i repot via webben. Bra signal — gå vidare till nästa steg.


      

        Funkar inte?
        
    
          
  • 404 "Repository not found" — du är troligen inloggad på fel GitHub-konto. Logga ut, klicka View invitation-länken i mejlet igen, logga in med rätt konto.
    • 
          
  • Invitation har gått ut — invitations är giltiga i 7 dagar. Be Niklaz skicka en ny.
    • 
        

      

    

  









  Steg 04 av 08
  
Installera GitHub CLI

  
Vi behöver ett verktyg som heter gh. Det gör att din dator kan hämta filer från GitHub utan att be om lösenord varje gång.


  

    

      
Vad du gör

      
1. Gå till nedladdningssidan i webbläsaren:

      

        
https://cli.github.com/

        
      

      
2. Klicka på den vita knappen Download for Mac.

      
3. Öppna den nedladdade .pkg-filen och följ stegen i installern. Precis som vilken Mac-app som helst.


      

        Använder du redan Homebrew? Du kan istället köra brew install gh i terminalen.
      

    


    

      
Vad du ser när det funkat

      
Verifiera installen med:

      

        
gh --version

        
      

      
Du borde se något i stil med:

      
gh version 2.x.x


      

        Funkar inte?
        
    
          
  • "command not found: gh" — installen är klar men terminalen ser inte den än. Stäng terminalen och öppna en ny.
    • 
        

      

    

  









  Steg 05 av 08
  
Logga in på GitHub via terminalen

  
Två kommandon. Det första loggar in dig på GitHub. Det andra ser till att inloggningen kommer ihåg dig — så du slipper logga in igen framöver.


  

    

      
Vad du gör

      
1. Kör i terminalen:

      

        
gh auth login

        
      

      
Följ promparna: välj GitHub.com, välj HTTPS, logga in via webbläsaren. Klicka Authorize i browsern när den frågar.

      
2. När du är tillbaka i terminalen — kör:

      

        
gh auth setup-git

        
      

      
Det här gör att alla framtida git-kommandon använder din GitHub-login utan att fråga om lösenord.

    


    

      
Vad du ser när det funkat

      
Efter gh auth login:

      
✓ Authentication complete.
✓ Logged in as @your-username

      
Efter gh auth setup-git:

      
✓ Configured git protocol


      

        Funkar inte?
        
    
          
  • Browsern öppnas inte automatiskt — kopiera URL:en som visas i terminalen och klistra in i webbläsaren manuellt.
    • 
          
  • "Authorization failed" — du loggade in på fel GitHub-konto. Kör gh auth logout och börja om.
    • 
        

      

    

  









  Steg 06 av 08
  
Hämta Lens Skill
(och aktivera auto-sync)

  
Nu placerar vi skill:en på din dator och kopplar den till GitHub så den synkar sig själv. Härifrån uppdaterar filen sig själv — när en kollega lägger till ny kunskap i skillen får du den senaste versionen automatiskt.


  

    

      
Vad du gör

      
1. Förbered mappen där Claude Code letar efter skills:

      

        
mkdir -p ~/.claude/skills

        
      

      
2. Klona skill:en till den mappen:

      

        
git clone https://github.com/niklazhallberg/valtech-radon-lens-studio-skill ~/.claude/skills/lens-studio-snapchat-filter

        
      

      
3. Kör install-scriptet — det aktiverar auto-sync:

      

        
~/.claude/skills/lens-studio-snapchat-filter/bin/install.sh

        
      

    


    

      
Vad du ser när det funkat

      
Klon-kommandot visar nedladdningens framsteg. Sedan kör install-scriptet en checklista och avslutar med:

      
🎉 Allt är på plats!

✅ Claude Code installerat
✅ Lens Studio verifierat
✅ Lens Studio-skillen installerad
✅ Auto-sync aktiverat

      
Auto-sync är nu igång — varje gång du startar Claude Code framöver hämtar den senaste kunskapen från GitHub automatiskt.


      

        Funkar inte?
        
    
          
  • "Repository not found" eller 404 vid klone — gå tillbaka till Steg 03 och bekräfta att invitationen accepterades med samma GitHub-konto du loggade in med i Steg 05.
    • 
          
  • Promptas för username/password — Steg 05's gh auth setup-git körde inte. Kör gh auth setup-git igen och prova klone på nytt.
    • 
          
  • install.sh klagar på saknat Node.js eller git — följ instruktionerna scriptet ger. Det är idempotent — säkert att köra om när du fixat det som saknades.
    • 
        

      

    

  









  Steg 07 av 08
  
Starta Claude Code

  
Nu öppnar du själva Claude-sessionen — det är där ni två (du och Claude) pratar.


  

    

      
Vad du gör

      
I samma terminal, skriv:

      

        
claude

        
      

      
Tryck Enter. Första gången du startar Claude Code öppnas en webbläsare för Anthropic-login. Logga in där, kom tillbaka till terminalen.


      

        Login-prompten frågar hur du vill logga in. Välj baserat på vägen du valde i "Innan du börjar":
        
    
          
  • Väg B (Pro/Max): "Claude account with subscription" — logga in via webbläsaren.
    • 
          
  • Väg C (API-credit): "Anthropic Console (API key)" — paste:a in din sk-ant-...-nyckel.
    • 
        

      


      

        Byta modell senare? När du är inne i Claude Code, skriv /model för att välja:
        
    
          
  • Haiku 4.5 — snabbast och billigast. Bra för enkla tasks och att spara credit under testfasen.
    • 
          
  • Sonnet 4.6 — default. Bra balans mellan smarthet och kostnad.
    • 
          
  • Opus 4.7 — starkast. Använd när du fastnar i komplex kod eller knepiga buggar.
    • 
        

      

    


    

      
Vad du ser när det funkat

      
I terminalen visas en prompt — en cursor som väntar på att du ska skriva. Något i stil med:

      
Welcome to Claude Code.

Type your message to begin:
> _

      
Det streckade understrecket (cursor) blinkar. Du är inne. Allt du skriver härifrån går direkt till Claude.


      

        Funkar inte?
        
    
          
  • "You need to log in" men ingen webbläsare öppnas — kopiera URL:en som visas i terminalen och klistra in i webbläsaren manuellt.
    • 
          
  • "Account not found / unauthorized" — ditt Anthropic-konto har inte access till Claude Code-API:n. Be Valtech-IT lägga till dig.
    • 
        

      

    

  









  Steg 08 av 08 · det här är magin
  
Aktivera skill:en

  
Sista steget. Säg till Claude vad du vill bygga — så aktiveras skill:en och hen tar över därifrån.


  

    

      
Vad du gör

      
Klistra in i Claude Code (cursor:n från Steg 07) — tryck Enter:

      

        
Time to wake up! Let’s create a Snapchat lens.

        
      

      
Det här är start-skottet. Från och med nu är det Claude som är din kollega — hen guidar dig genom Lens Studio-setup, projekt-onboarding och hela filter-bygget.


      

        Är du osäker på något steg framöver? Säg det till Claude i klartext: "Jag förstår inte vad du menar med [X]". Hen omformulerar och förklarar enklare.
      

    


    

      
Vad du ser när det funkat

      
Claude svarar med att aktivera skill:en + onboarding-flow. Något i stil med:

      
Hej! Skill:en är aktiv. Innan vi börjar — har du
Lens Studio installerat på datorn? (Det är där vi
bygger filtret.)

Berätta också lite om filtret du vill göra:
- Vilken klient/projekt?
- Grov idé — vad ska användaren uppleva?

      
Härifrån är det inte längre manualen som styr. Du följer Claude. Hen är en kollega som vet vad hen gör.

    

  









  Allt går inte enligt plan
  
Fastnar du?

  
Det här är nytt — du kommer förmodligen fastna någonstans. Det är helt okej. Här är tre vägar framåt.


  

    

      
1. Be en kollega

      
På Valtech finns andra som kört detta. Skriv i er Slack-kanal (#snapchat-filter eller motsvarande) och peka på det steg som krånglar. Någon har troligen sett samma sak.

    


    

      
2. Fråga Claude Code direkt

      
Har du fått Claude Code att starta? Skriv bara "Jag fastnar på <steg>: <vad du ser>". Claude växlar till felsökning automatiskt — hen frågar tillbaka tills hen förstår, och föreslår en fix.

    


    

      
3. Fråga en annan AI

      
Ingen Claude Code att fråga än? Kopiera kommandot eller felmeddelandet, klistra in i claude.ai, ChatGPT eller Gemini. Lägg till "jag försöker installera Claude Code för att bygga Snapchat-filter" så de förstår kontexten.

    


    

      
4. Visa mig din skärm

      
Använd din dators skärmdump-funktion (Mac: ⌘+⇧+4, Windows: Win+⇧+S). Ta bild på vad du ser i terminalen. Klistra in bilden direkt i Claude.ai eller ChatGPT — de kan SE vad som gått fel.

      
Många nybörjare vet inte hur man beskriver ett fel i text. En screenshot är enklare.
