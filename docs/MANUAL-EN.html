  Step 01 of 04
  
Install Claude Code

  
Claude Code is the brain that builds your filter. It runs locally on your own machine — no cloud, no separate account beyond your Anthropic login.


  

    

      
What you do

      
1. Open the Terminal app (Mac: ⌘+Space, type "Terminal", hit Enter). Paste this and press Enter — the install takes a minute or so:

      

        
curl -fsSL https://claude.ai/install.sh | bash

        
      

      
2. When the install is done — verify with this in the same terminal:

      

        
claude --version

        
      

    


    

      
What you see when it worked

      
In the terminal, after claude --version, you should see a version number:

      
claude code 1.x.x

      
The exact number doesn't matter — what matters is that you get a response (not "command not found").


      

        Not working?
        
    
          
  • "command not found: claude" — the install ran, but the terminal doesn't know where claude lives yet. Close the terminal, open a new one. Usually fixes it.
    • 
          
  • The curl command crashes — most common cause is the internet broke mid-install. Run the same command again.
    • 
          
  • Don't know what Terminal is — it's a black or dark-green window where you type commands instead of clicking. Open Spotlight (⌘+Space) and type "Terminal".
    • 
        

      

    

  









  Step 02 of 04
  
Start Claude Code

  
Now you open the Claude session itself — that's where the two of you (you and Claude) actually talk.


  

    

      
What you do

      
In the same terminal, type:

      

        
claude

        
      

      
Press Enter.

      
The first time you start Claude Code it'll ask you to log in via the browser — it automatically opens a page at Anthropic. Log in there, come back to the terminal.


      

        Need an account? Claude Code requires an Anthropic account. If you don't have one — ask your lead or IT for access via Valtech's account. Otherwise you can get stuck at login without understanding why.
      

    


    

      
What you see when it worked

      
The terminal shows a prompt — a cursor waiting for you to type. Something like:

      
Welcome to Claude Code.

Type your message to begin:
> _

      
The underscore (cursor) blinks. You're in. Everything you type from here goes straight to Claude.


      

        Not working?
        
    
          
  • "You need to log in" but no browser opens — copy the URL shown in the terminal and paste it into your browser manually.
    • 
          
  • "Account not found / unauthorized" — your Anthropic account doesn't have access to the Claude Code API. Ask Valtech IT to add you.
    • 
        

      

    

  













  Step 03 of 04 · this is the magic
  
Paste the setup prompt

  
This is the only thing you really need to remember. Copy the text below, paste it into Claude Code, press Enter. Claude takes over from there — diagnoses what you have, what's missing, and walks you through it.


  

    

      SETUP PROMPT — copy the whole thing
    

    
I'm a new user who wants to build a Snapchat filter via you and Lens Studio. I just installed you (Claude Code) and nothing else is in place yet. Help me get started.

First, run a diagnostic on what exists / is missing on my machine:

1. Lens Studio installed? Check if the folder `/Applications/Lens Studio.app` exists on Mac, or if `lens-studio` is in PATH on Windows/Linux.

2. Is the lens-studio-snapchat-filter skill installed? Check if `~/.claude/skills/lens-studio-snapchat-filter/SKILL.md` exists.

3. MCP server registered between you and Lens Studio? Run `claude mcp list` and look for a row with `lens-studio`.

Report what you found — what's there, what's missing. Then guide me through what's missing, one step at a time. Wait for my 'done' after each step before moving on.

Explain each step in plain language. I'm a digital designer, not a developer. Use mentor tone — you're a colleague helping me, not a system running a setup wizard. Tell me what I'll see in Lens Studio and in the terminal when each step succeeds.

When everything is in place: ask what my lens project is about (client + rough idea) and run your usual onboarding questions. You're the filter-build expert now — guide me all the way from idea to submission.

    
  


  

    

      
What you do

      
1. Click "Copy all" on the block above.

      
2. Go back to the Claude Code terminal (where the cursor was blinking).

      
3. Paste: ⌘+V on Mac, Ctrl+V on Windows.

      
4. Press Enter.


      

        It's fine to paste a long block of text into the terminal. Claude Code can handle multiple lines at once. You don't need to press Enter between lines.
      

    


    

      
What you see when it worked

      
Claude starts replying — first with "Running a diagnostic..." or similar. Then lists what's there and what's missing on your machine. Something like:

      
Checking your machine now...

✓ Claude Code: running (that's you talking to me)
✗ Lens Studio: app not found
✗ Filter skill: not installed
✗ MCP server: not registered

We need to fix three things. We'll take them one at a time...

      
Then Claude walks you through the first step — installing Lens Studio. You follow their guidance. From here it's THEM, not the manual.

    

  











  Step 04 of 04
  
Follow Claude's guidance

  
From here you're no longer following a manual. You're following Claude. They're a colleague who knows what they're doing.


  

    

      
What you do

      
Claude will tell you what the next step is. It might be:

      
    
        
  • Download Lens Studio from ar.snap.com
    • 
        
  • Click a specific button in Lens Studio
    • 
        
  • Paste a configuration into the terminal
    • 
        
  • Save a file
    • 
      

      
When you've done the step — type "done" in the terminal, press Enter. Claude verifies and moves on.


      

        Unsure about a step? Tell Claude in plain language: "I don't understand what you mean by [X]". They'll rephrase and explain it more simply.
      

    


    

      
What you see when everything's ready

      
When all three missing pieces (Lens Studio, skill, MCP) are in place, Claude says:

      
Everything in place — now we can start building.

Tell me a bit about the filter you want to make:
- Which client/project?
- Rough idea — what should the user experience?
- Timeline if you have one

I'll pull up the onboarding questions once you answer.

      
That's the starting gun. From here on it's filter-building — Claude knows the whole path from idea to a finished lens.

    

  









  Not everything goes to plan
  
Stuck?

  
This is new and unusual. You'll get stuck on something. That's OK, and there are several ways forward.


  

    

      
1. Ask Claude Code directly

      
Got Claude Code running? Just type "I'm stuck on <step>: <what you see>". Claude switches to troubleshooting automatically — asks back until it understands, and suggests a fix.

    


    

      
2. Ask another AI

      
No Claude Code yet to ask? Copy the command or the error message, paste it into claude.ai, ChatGPT, or Gemini. Add "I'm trying to install Claude Code to build Snapchat filters" so they understand the context.

    


    

      
3. Ask a colleague

      
Others at Valtech have done this. Post in your Slack channel (#snapchat-filter or equivalent) and point at the step that's misbehaving. Someone has probably seen the same thing.

    


    

      
4. Show me your screen

      
Use your computer's screenshot tool (Mac: ⌘+⇧+4, Windows: Win+⇧+S). Grab what you see in the terminal. Paste the image straight into Claude.ai or ChatGPT — they can SEE what went wrong.

      
Many beginners don't know how to describe an error in text. A screenshot is easier.

    

  









  Once setup is done
  
What you can build

  
Lens Studio + Claude Code lets you build pretty much anything. Here are a few common first projects to get a feel for what's possible.


  

    

      
Logo that follows the face

      
Brand logo or text that flies in when the user opens the filter, anchored to the forehead or above the shoulder. Simple face tracking + 2D image.

    

    

      
Hat, glasses, or jewelry

      
3D model "worn" by the user. Works for caps, snapbacks, rings, necklaces, earrings. Snap has ready-made Try-On Packs to start from.

    

    

      
Sneakers on the feet

      
Classic try-on filter: shoes that follow the user's feet. We've got empirical experience with this in the skill — Claude knows the way.

    

    

      
Tap-to-reveal effect

      
User taps the screen, something fades in or animates — great for campaign reveals or "scratch the surface" mechanics.

    

  


  
When you have an idea — tell Claude and they'll pull up the onboarding questions. ~8 questions in 3 blocks (vision, constraints, assets), ~10 min total. Then the build begins.
