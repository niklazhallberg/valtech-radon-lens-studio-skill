  Before you start
  
Get a Claude account

  
Claude Code needs a paid login or your own API credits — a free claude.ai chat account is not enough. There are three paths; open the one that fits you.


  

    A. Enterprise subscription (recommended — on the way)
    
On the way — more information coming later.

    
Until then — pick path B or C below.

  


  

    B. Your own Claude Pro subscription ($17–20/mo)
    
Good if you want a predictable monthly cost or already have a Pro subscription.

    
1. Go to claude.com/pricing in your browser.

    
2. Pick Claude Pro and sign up.

    
3. Register with your @valtech.com address (or Google/Microsoft SSO).

    
4. Done. Later in Step 07 when you run claude in the terminal — pick "Claude account with subscription" at the login prompt.

  


  

    C. Your own API credits ($5–20, pay-as-you-go)
    
Best if you just want to try things out. No monthly commitment — you top up credits and burn them per use.

    
1. Go to platform.claude.com/login.

    
2. Register with your @valtech.com address (or "Continue with Google/Microsoft").

    
3. Pick "Individual" in the onboarding flow.

    
4. Go to API Keys → Create Key. Save the key (sk-ant-...) somewhere safe — it's only shown once.

    
5. Go to Billing → top up at least $10 with a card.

    
6. Later in Step 07 when you run claude in the terminal — pick "Anthropic Console (API key)" and paste your key.

    

      What it actually costs: Sonnet 4.6 — roughly $0.50–$3 per 30-minute Claude Code session. Haiku 4.5 — roughly $0.10–$0.50. Your balance updates in real time on the Console.
    

  









  Step 01 of 08
  
Install Claude Code

  
Claude Code is the brain that builds your filter — built by Anthropic, the company behind the AI model Claude. It runs locally on your own machine, and the only account you need is your Anthropic login.


  

    

      
What you do

      
1. Open the Terminal app (Mac: ⌘+Space, type "Terminal", hit Enter).

      
2. Paste this and press Enter — the install takes a minute or so:

      

        
curl -fsSL https://claude.ai/install.sh | bash

        
      

    


    

      
What you see when it worked

      
The terminal shows download + install steps, something like:

      
Downloading Claude Code...
Installing to /usr/local/bin/claude
Installation complete.

      
When the prompt is back and you can type again — the install is done.


      

        Not working?
        
    
          
  • The curl command crashes — most common cause is the internet broke mid-install. Run the same command again.
    • 
          
  • Don't know what Terminal is — it's a black or dark-green window where you type commands instead of clicking. Open Spotlight (⌘+Space) and type "Terminal".
    • 
        

      

    

  









  Step 02 of 08
  
Verify the installation

  
Before we move on — confirm that the claude command is actually reachable from your terminal.


  

    

      
What you do

      
In the same terminal, run:

      

        
claude --version

        
      

    


    

      
What you see when it worked

      
A version number:

      
claude code 1.x.x

      
The exact number doesn't matter — what matters is that you get a response (not "command not found").


      

        Not working?
        
    
          
  • "command not found: claude" — the install ran, but the terminal doesn't know where claude lives yet. Close the terminal, open a new one. Usually fixes it.
    • 
        

      

    

  









  Step 03 of 08
  
Accept the invitation

  
The skill lives on GitHub as a private repo. Niklaz has sent you an invitation — you need to accept it to gain access.

  
GitHub is a shared archive for code and files — think Google Drive but for development projects. The skill is stored there so everyone on the team can pull it down, use it, and improve it over time.


  

    

      
What you do

      
1. Open the email from Niklaz Hallberg.

      
2. Click the blue View invitation button.

      
3. If GitHub asks you to sign in — sign in. If you don't have an account yet, click Create an account, sign up, and verify your email.

      
4. Once signed in, you'll see a GitHub page with the invitation. Click Accept invitation.


      

        Use the same email address the invitation was sent to. Otherwise GitHub may show a 404 (Repository not found).
      

    


    

      
What you see when it worked

      
After clicking Accept invitation, the GitHub repo's front page shows a confirmation:

      
You are now a collaborator on
niklazhallberg/valtech-radon-lens-studio-skill

      
You can now see the repo files via the web. Good signal — move on to the next step.


      

        Not working?
        
    
          
  • 404 "Repository not found" — you're probably signed into the wrong GitHub account. Sign out, click View invitation in the email again, sign in with the right account.
    • 
          
  • Invitation expired — invitations are valid for 7 days. Ask Niklaz to send a new one.
    • 
        

      

    

  









  Step 04 of 08
  
Install GitHub CLI

  
We need a tool called gh. It lets your machine pull files from GitHub without asking for a password every time.


  

    

      
What you do

      
1. Go to the download page in your browser:

      

        
https://cli.github.com/

        
      

      
2. Click the white Download for Mac button.

      
3. Open the downloaded .pkg file and follow the installer steps. Just like any other Mac app.


      

        Already using Homebrew? You can instead run brew install gh in the terminal.
      

    


    

      
What you see when it worked

      
Verify the install with:

      

        
gh --version

        
      

      
You should see something like:

      
gh version 2.x.x


      

        Not working?
        
    
          
  • "command not found: gh" — the install is done but the terminal doesn't see it yet. Close the terminal and open a new one.
    • 
        

      

    

  









  Step 05 of 08
  
Sign in to GitHub from the terminal

  
Two commands. The first signs you in to GitHub. The second makes the sign-in stick — so you don't have to log in again later.


  

    

      
What you do

      
1. In the terminal, run:

      

        
gh auth login

        
      

      
Follow the prompts: choose GitHub.com, choose HTTPS, log in via the browser. Click Authorize in the browser when asked.

      
2. Once back in the terminal — run:

      

        
gh auth setup-git

        
      

      
This makes all future git commands use your GitHub login without asking for a password.

    


    

      
What you see when it worked

      
After gh auth login:

      
✓ Authentication complete.
✓ Logged in as @your-username

      
After gh auth setup-git:

      
✓ Configured git protocol


      

        Not working?
        
    
          
  • Browser doesn't open automatically — copy the URL shown in the terminal and paste it into your browser manually.
    • 
          
  • "Authorization failed" — you signed in with the wrong GitHub account. Run gh auth logout and start over.
    • 
        

      

    

  









  Step 06 of 08
  
Download the Lens Skill

  
Now we can download the skill to your machine. Thanks to the sign-in from the previous step, it happens without any extra prompts.


  

    

      
What you do

      
In the terminal, run:

      

        
git clone https://github.com/niklazhallberg/valtech-radon-lens-studio-skill

        
      

      
The files download to a new folder in your current terminal location.

    


    

      
What you see when it worked

      
Cloning into 'valtech-radon-lens-studio-skill'...
remote: Enumerating objects: ...
Receiving objects: 100% ... done.

      
When you run ls you'll now see the folder valtech-radon-lens-studio-skill/.


      

        Not working?
        
    
          
  • "Repository not found" or 404 — go back to Step 03 and confirm the invitation was accepted with the same GitHub account you signed in with in Step 05.
    • 
          
  • Prompted for username/password — Step 05's gh auth setup-git didn't run. Run gh auth setup-git again and try the clone once more.
    • 
        

      

    

  









  Step 07 of 08
  
Start Claude Code

  
Now you open the Claude session itself — that's where the two of you (you and Claude) actually talk.


  

    

      
What you do

      
In the same terminal, type:

      

        
claude

        
      

      
Press Enter. The first time you start Claude Code, a browser opens for Anthropic login. Log in there, come back to the terminal.


      

        The login prompt asks how you want to sign in. Pick the option that matches the path you chose in "Before you start":
        
    
          
  • Path B (Pro/Max): "Claude account with subscription" — log in through the browser.
    • 
          
  • Path C (API credits): "Anthropic Console (API key)" — paste your sk-ant-... key.
    • 
        

      


      

        Switch model later? Once you're inside Claude Code, type /model to pick:
        
    
          
  • Haiku 4.5 — fastest and cheapest. Good for simple tasks and saving credit during testing.
    • 
          
  • Sonnet 4.6 — default. Good balance of intelligence and cost.
    • 
          
  • Opus 4.7 — strongest. Use when you're stuck on complex code or tricky bugs.
    • 
        

      

    


    

      
What you see when it worked

      
The terminal shows a prompt — a cursor waiting for you to type. Something like:

      
Welcome to Claude Code.

Type your message to begin:
> _

      
The underscore (cursor) blinks. You're in. Everything you type from here goes straight to Claude.


      

        Not working?
        
    
          
  • "You need to log in" but no browser opens — copy the URL shown in the terminal and paste it into your browser manually.
    • 
          
  • "Account not found / unauthorized" — your Anthropic account doesn't have access to the Claude Code API. Ask Valtech IT to add you.
    •

Activate the skill

  
Last step. Tell Claude what you want to build — and the skill activates and takes over from there.

Claude replies by activating the skill + the onboarding flow. Something like:

      
Hey! The skill is active. Before we begin — do you

From here it's no longer the manual driving. You're following Claude. They're a colleague who knows what they're doing.

    

  









  Not everything goes to plan
  
Stuck?

  
This is new — you'll probably get stuck somewhere. That's completely fine. Here are three ways forward.


  

    

      
1. Ask a colleague

      
Others at Valtech have done this. Post in your Slack channel (#snapchat-filter or equivalent) and point at the step that's misbehaving. Someone has probably seen the same thing.

    


    

      
2. Ask Claude Code directly

      
Got Claude Code running? Just type "I'm stuck on <step>: <what you see>". Claude switches to troubleshooting automatically — asks back until it understands, and suggests a fix.

    


    

      
3. Ask another AI

      
No Claude Code yet to ask? Copy the command or the error message, paste it into claude.ai, ChatGPT, or Gemini. Add "I'm trying to install Claude Code to build Snapchat filters" so they understand the context.

    


    

      
4. Show me your screen

      
Use your computer's screenshot tool (Mac: ⌘+⇧+4, Windows: Win+⇧+S). Grab what you see in the terminal. Paste the image straight into Claude.ai or ChatGPT — they can SEE what went wrong.

      
Many beginners don't know how to describe an error in text. A screenshot is easier.
